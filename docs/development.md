# 開發與執行說明

## 直接開啟產品展示

在儲存庫根目錄執行：

```bash
python3 -m http.server 8080 --bind 127.0.0.1 --directory static
```

瀏覽 `http://127.0.0.1:8080/`。按 Ctrl+C 停止。只提供本機靜態檔案，不啟動模型或問答 API；無需 key、套件安裝或模型下載。

`static/index.html` 為產品落地頁，`static/app.html` 為有明確展示標示的介面導覽。字型、程式與圖片均在本庫，不使用執行期外部字型 CDN。桌面瀏覽為主，沒有手機版驗收。

## 程式閱讀快照

`src/` 保留本機問答核心，供閱讀對話狀態、來源授權、回合提交、檢索與證據整理邏輯。公開匯出已將作者電腦的絕對路徑改為設定：

| 變數 | 用途 | 預設 |
| --- | --- | --- |
| CAMPUS_RAG_ROOT | 另備的本機語料、索引、模型與相關檢索依賴根目錄 | `./local-data` |
| CAMPUS_RAG_PYTHON | 檢索子程序使用的 Python | 當前 Python |

**設定路徑本身不會下載或建立缺少的資料。** 完整環境尚未封裝成可移植發行包；不建議直接執行 `src/server.py` 期待得到完整服務。本庫也不附 API key、正式向量庫或校方完整文件。

核心的字型與網頁資產在 `src/web/`；模型相關的本機依賴為 torch、transformers、sentence-transformers、chromadb 與 numpy。版本相容性與完整資料重建仍需要獨立處理，沒有宣稱此公開快照已通過全平台整合。

## 可獨立執行的合成測試

```bash
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s src/tests -p 'test_conversation.py'
```

這組測試使用合成 Backend，不載模型，也不證明文件正確或向量品質。完整本機版的語料測試沒有複製到公開庫，避免把缺少資料的測試誤包成能直接重現。

## 字體層次

導讀300、一般正文400、局部重點500、標題600、主標關鍵字700。奶油紙色搭配炭黑與較深磚紅作功能文字；裝飾保留紅、藍、黃筆刷。字型授權見[第三方說明](../THIRD_PARTY_NOTICES.md)。

## 公開內容邊界

此儲存庫以檔案白名單整理。只放產品素材和功能程式，不附私人面試稿、個人企劃、原始聊天、內部協作紀錄、帳密、環境檔、模型權重、向量庫與執行日誌。展示截圖僅含一般論文示例提問。
