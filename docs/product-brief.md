# 你要畢業了嗎｜產品介紹

**把散在公告裡的畢業規定，整理成有原文可查的下一步。**

研究生辦理論文、口試與離校時，常需要交叉查閱圖書館、系所與教務單位的文件。這個桌面問答原型聚焦「問清楚、接著問、回去核對」三件事。

## 可以看見的功能

| 功能 | 使用方式 |
| --- | --- |
| 先整理重點 | 先呈現文件支持的答案、條件與例外，減少直接堆疊原文。 |
| 接續追問 | 本機問答版可在同一聊天補充條件；不同聊天分開保存上下文。 |
| 核對依據 | 回答附重要引文，可再展開來源與對應片段。 |
| 說明不確定性 | 個人適用年度、版本或依據不足時，揭露限制與查證方向。 |

公開展示頁提供固定示例、產品說明與實際介面截圖。固定示例不會即時搜尋，也不代表已替使用者確認適用規定。

## 本機原型如何工作

1. 整理已留存文件，按條文與語意單位切分，保留條件、例外與來源定位。
2. 以詞彙檢索及 `BGE-large-zh-v1.5` 中文向量檢索分別召回候選，再以 RRF 融合排名。
3. 向量以 CLS pooling 取出並做 L2 正規化，輸出 1024 維；由 Chroma 保存向量與片段中繼資料，使用 cosine 距離檢索。
4. 依證據與條件規則整理回答，附來源片段；沒有接入生成式語言模型來自由撰寫答案。

目前語料為 31 個原始片段，正式比較使用其中 28 個候選片段。這是小範圍技術驗證，尚不能外推全校規模或任意自然語言問題。

## 驗證結果與界線

同一批 10 題主評估題的首輪比較：

| 指標 | 詞彙檢索 B0 | 向量檢索 B1 | RRF 融合 B2 |
| --- | ---: | ---: | ---: |
| Hit@1 | 0.40 | 0.50 | 0.60 |
| Hit@5 | 1.00 | 1.00 | 1.00 |
| Complete@10 | 1.00 | 0.80 | 0.80 |
| MRR@5 | 0.6533 | 0.7500 | 0.7750 |

Hit@k 表示前 k 筆是否命中所需證據；Complete@k 則要求該題所需的證據組合完整。融合在這一小批題目的首位命中與排序表現較好，但向量與融合的證據完整率沒有全面超過詞彙檢索，因此不能宣稱「向量一定更好」。

本次產品展示與排版改版另通過 49 項既有單元測試及 12 項隔離 HTTP 檢查。這些是特定範圍的功能回歸證據，不是全部校規事實正確率，也不是大型真人使用研究。

## 目前限制

- 非官方專案，先聚焦研究生論文、口試及離校文件，並未涵蓋全校所有單位。
- 尚未核實文件對每位使用者的年度與版本適用關係；入學年不能直接證明適用哪版規定。
- 本機聊天記憶不永久保存；服務重啟或工作階段失效後會重置，閒置工作階段約一小時到期。
- 真實檢索原型需要既有模型、語料及本機執行環境；公開靜態展示不包含這些依賴，不能等同完整客服服務。
- 最終仍應以權責單位公告與承辦確認為準。

體驗步驟見 [使用說明](usage.md)。
