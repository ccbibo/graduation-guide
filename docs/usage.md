# 使用說明

公開版本用來展示《你要畢業了嗎》的產品價值、回答方式與桌面介面。**固定示例和截圖不是即時問答服務。**

## 在自己的電腦開啟展示

準備 Python 3，在此儲存庫根目錄執行：

```bash
python3 -m http.server 8080 --bind 127.0.0.1 --directory static
```

開啟 <http://127.0.0.1:8080/>。終端機按 Ctrl + C 可停止。此模式只提供本機靜態網頁，不會下載模型、建立向量庫或呼叫 API。

## 瀏覽公開展示

1. 從產品首頁閱讀「少跑一趟，從問清楚開始」，了解作品解決的問題。
2. 前往「看它怎麼回答」，切換列印方式、收件份數與適用條件三個示例。
3. 先看整理後的重點，再按「看重要原文與依據」展開文件片段。
4. 閱讀「答案從哪裡來」與本版範圍，區分文件內容、個人適用性及尚待核實的地方。

`static/app.html` 是展示導覽頁，以問答截圖和說明呈現完整原型的操作方式；它不是可以自由提問的聊天介面。

頁籤支援方向鍵、Home 與 End；來源展開可透過鍵盤操作。介面以桌面瀏覽為目標，並支援減少動態效果的系統偏好。

## 本機完整問答版

以下功能屬於已準備好語料、模型與執行依賴的本機原型，公開靜態展示不會自動提供：

1. 從本機產品首頁進入問答。
2. 輸入問題，例如「我的論文只有 60 頁，可以單面列印嗎？」。
3. 閱讀整理後的答案、條件分支與適用性限制；依需要補充系所、學位等相關條件。
4. 點引用或展開來源，核對正式文件的對應片段。
5. 在同一聊天接著追問；若要討論另一組條件，新增一個聊天，避免混用上下文。

Enter 送出、Shift + Enter 換行。每個聊天的上下文分開保存；重啟服務或工作階段到期後，不會永久保留記憶。

儲存庫的 `src/` 另保留經整理的實際 UI、後端及檢索核心程式供閱讀；沒有附模型權重、校方文件全文或正式向量庫，不能直接把靜態啟動命令當成完整 RAG 安裝方式，也不能宣稱 clone 後即可執行真正檢索。

## 建議觀察的問題

| 問題 | 可以觀察什麼 |
| --- | --- |
| 我的論文只有 60 頁，可以單面列印嗎？ | 是否分清「可以」與「必須」，並保留文件條件。 |
| 紙本論文到底交幾本？ | 是否分清收件單位，避免把不同規定直接加總。 |
| 我是 115 學年度入學，這份規定一定適用我嗎？ | 是否承認版本適用性尚待核實，不直接用入學年推定。 |

這些問題是展示方向，不是承諾任何身分、系所或年度都能得到確定答案。正式辦理前，仍須核對權責單位的最新公告。

## 如何閱讀來源

先看重要引文，再展開完整片段。文件出處可核對，不等於該文件對每位使用者都現行適用；來源定位、版本與個人條件需要分別確認。遇到待核實標示時，請保留問題與來源，向承辦單位確認。

更多架構、評估與限制見 [產品介紹](product-brief.md)。
